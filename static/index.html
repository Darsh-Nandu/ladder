How Ladder works

  1. Triage (optional). Nemotron 3 Nano reads the spec and rates difficulty, picking the first rung.
  2. Tests. If you give no tests, Nemotron 3 Super writes a unit-test suite from the spec.
  3. Write → run → repair. The current rung writes a full solution. It runs in a sandbox with no network, CPU and memory limits and a scrubbed environment. Failures go back to the model with the exact assertion and line.
  4. Escalate. After two failed attempts on a rung, the agent climbs: Nano → Super → Ultra (reasoning on). The higher rung sees the full failure history and may repair a test only if it provably contradicts the spec. Your own tests are never touched.
  5. Account. Every call is metered in tokens, dollars and seconds, so you can see exactly what the answer cost and what it would have cost on Ultra alone.

All inference runs on Nebius Token Factory through its OpenAI-compatible API, using NVIDIA Nemotron 3 open models.
